Research question

Can a computer pick appliance start times that cut a Moldovan household’s bill under a two-zone tariff, without ever overloading the main fuse — and which algorithm does it best?

  • H1 Optimised schedules beat habit.
  • H2 Annealing and genetic search beat greedy when the fuse is tight.
  • H3 The saving is capped by (1 − night/day price).
  • H4 Exact search stops scaling; metaheuristics keep working.

Written before the first full run; verdicts computed from data. All four supported.

How it works

Input appliances, windows, habits, 24 hourly prices, fuse limit
Model cost = Σ power × price + overload penalty
Solvers habit · greedy · annealing · genetic · exact, equal 2400 evaluations
Output schedule, cost, saving, fuse check — in ms, in the browser

React + Vite · pure JavaScript algorithms · 50 automated tests · npm run benchmark reproduces every number · EN / RO / RU

Honest limits

  • Synthetic households; no Moldovan meter data yet.
  • Tariff from Premier Energy’s official page (VAT basis not stated); the tool accepts your own prices.
  • Searches start from greedy, so part of their edge over greedy is built in.
  • Annealing still fails on some hard tight-fuse cases (28/100 runs on one household).

Responsible AI

The author set the question, hypotheses and experiments and reviewed every result. Claude Code — the only AI tool used — wrote code and drafts under that direction. Its mistakes (a baseline that broke the fuse, infeasible schedules counted in gaps, random starts) were found by tests and review and are logged in docs/research/LOGBOOK.md.
